# メニュー終了とサービス終了を連動する

Q22により、設定完了後のログイン時起動を採用し、メニューアプリが終了したときは製品の同期・取り込み・Viewerサービスも終了する。既存実装と前ラウンド推奨の「Menuだけ終了し、同期を継続する」という動作を見直す。

メニューアプリと製品のバックグラウンド動作の境界を一致させ、終了後に独立したKeepAliveがサービスを立ち上げ直す構成にしない。各機能のON/OFF設定は保持し、次回起動へ引き継ぐ。

状態や設定のウィンドウを閉じる操作と、メニューアプリ自体を終了する操作は区別する。Q27により、ブラウザ拡張側の未送信状態は保持し、次回製品起動時に元履歴を確認して再開する。拡張自体は無効化せず、Mac側サービスを勝手に起動しない。開始済み処理の完了・中断を含む終了手順は、この境界を満たすよう実装・検証する。既存の終了処理がこれらを既に保証しているとは扱わない。
