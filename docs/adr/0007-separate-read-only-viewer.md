# FDAを持たないViewerを別プロセスにする

ユーザーのQ14により、Web API/UIを提供するViewerはAgentと別プロセスにする。ViewerはFDAと同期用の秘密鍵を持たず、統合DBを読み取り専用で参照する。収集とブラウザ履歴の照合による書き込みはAgent側が担当する。

閲覧をFDA付きAgentへ同居させる案と比べ、Web入力や重い検索とブラウザへの書き込みの境界を分ける。Q16〜Q18により、非表示・ユーザー設定の収集除外・製品内手動削除は実装しない。Webは閲覧専用を維持する。

Q15により、一部の収集元が読めなくても、保存済み履歴の閲覧と、読める収集元の取り込みを続ける。失敗した収集元と最終成功時刻を表示する。統合DB自体の互換性や安全な読取が確認できない場合の提供可否は、この収集元別の継続方針と分けて扱う。
