# 統合DBに履歴を蓄積し、別保管を作らない

2026-11-13のQ18により、削除非追従の保持方針は[ADR-0008](0008-browser-owned-history.md)で見直した。以下は当初の判断の記録。別保管を作らない判断は維持する。

ユーザーのQ8=Cにより、旧HistorySyncと同様に収集済み履歴を統合DBへ蓄積する。ブラウザ側の削除・保存期限には追従せず、統合DBの履歴に独自の自動保存期限を設けない。統合製品が現在のDBとは別に世代コピーやバックアップを作成・保持する機能は設けない。

Q2の「アーカイブは残さない」は、別保管を作らないという意味に具体化された。元ブラウザと同じ保持範囲へそろえる案や、閲覧時だけ元ブラウザを直接読む案を採用せず、過去の閲覧を統合DBから振り返る方式を維持する。

この判断により、ブラウザ側で削除・期限切れとなった履歴も統合製品では参照できる。統合DB内の非表示・除外・明示削除の具体的な操作は別に定める。Q9により既存HistorySyncの保存領域からのデータ移行は行わず、保存対象のブラウザから収集を始める。
