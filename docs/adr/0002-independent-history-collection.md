# 取り込みの対象と停止状態をブラウザ間同期から分ける

初期の保存対象はこのMacのSafariと選択したEdge/Chromeプロファイルとし、同期相手とは別に選ぶ。ブラウザ間同期を停止しても取り込みと閲覧は継続し、取り込みを止める操作は別にする。ユーザーのQ3・Q4の回答による。

既存の単一active profileと同期有効状態を、閲覧用履歴の取得条件へそのまま流用すると、同期先の切替や停止で保存範囲・鮮度まで変わる。取り込みの対象と状態を独立させ、ブラウザ間の配送と過去履歴の閲覧を別々に制御する。

Q6の回答により、Safari起動・Sync Assistの既存条件は維持し、収集のための追加の自動起動条件を設けない。iPhoneで閲覧しただけでMacのSafariが停止し、Agent自身の対象配送がなければ、統合製品は受信のためにSafariを起動しない。

Q12により、取り込み再開時は元ブラウザに残っている履歴を補う。Q13により、通常運用の保存反映はMac到着から1分以内を目標とし、手動取り込みも提供する。

Q30により、設定で保存対象から外した収集元のデータは統合DBからも取り除く。取り込みの一時停止では保存済みデータを維持し、保存対象の解除とは区別する。再選択すれば元ブラウザに残る分を再取得する。
