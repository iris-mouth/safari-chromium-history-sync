# 旧HistorySyncのデータを移行せず、ブラウザから収集する

ユーザーのQ9により、既存HistorySyncのDB・設定・アイコンキャッシュを新製品へ取り込む移行機能は作らない。新しい統合DBを作り、保存対象に選んだブラウザの履歴を直接収集する。Q23により粒度は元ブラウザの訪問記録単位へ変更した。

旧DB互換のデータ移行・出典対応・非表示設定のマージより、現在ブラウザに残っている履歴から統合製品の運用を始めることを優先する。ブラウザから既に消えて旧HistorySyncにだけ残る履歴は、新製品の初期データには含まれない。既存HistorySyncの保存領域や設定を変更する操作は行わない。

Q31により、初期のSafariは現在の同期が使う標準の履歴DB1つを扱う。複数Safariプロファイルは後段とし、Chrome/Edgeは保存対象に選んだプロファイルを扱う。
